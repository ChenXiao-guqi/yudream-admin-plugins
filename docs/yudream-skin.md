# Minecraft 皮肤与衣柜

## 个人仪表盘

从 1.5.0 起，`/platform/plugins/yudream-skin/dashboard` 同时展示个人角色概况、当前穿着和完整衣柜。

- 衣柜支持名称搜索、皮肤/披风筛选和分页。点击整张卡片选择外观，“已选中”与“已装备”分别表示试穿选择和角色实际装备。
- 换装预览将所选外观与目标角色另一栏装备组合。选择卡片只改变预览，点击“应用到角色”才保存；切换目标角色后，当前穿着、预览和已装备状态一起更新。
- 可以直接重命名收藏或确认移出衣柜。重命名失败时保留输入；移出收藏不删除材质，也不更改角色已经装备的外观。
- 应用衣柜外观不会重复收藏或覆盖衣柜显示名称。皮肤库应用已收藏材质时也保留收藏名称。
- “我的角色”和“皮肤库”仍为独立页面，承担角色维护与材质浏览、上传等操作。

个人“我的衣柜”菜单已隐藏。旧 `/platform/plugins/yudream-skin/closet` 路径和远程组件键继续可用，打开同一仪表盘并定位衣柜区域。

## 权限与管理

个人角色和衣柜始终通过 `/me/**` 接口访问，只展示当前账号的数据。仅有查看权限的账号可浏览皮肤库，仪表盘说明个人功能需要“使用皮肤站”权限。

管理员的角色、材质与衣柜维护继续使用独立 `/admin/**` 页面和接口。管理权限不会扩大个人仪表盘的数据范围。
